## [0.1.0] - 2026-10-20

### Added
- Initial public release of the official Mozhi landing page.
- Single-page editorial architecture built on Next.js 16 (App Router), React 19, and Tailwind CSS v4.
- Floating Island navigation with smooth anchor scrolling and mobile menu.
- Interactive Test Bench showcasing 3 engineering prompt scenarios across all 4 rewrite modes (Typo & Grammar, Level 1 Light, Level 2 Balanced, Level 3 Advanced).
- Dual-engine architecture matrix comparing local WebGPU/WASM SmolLM2 inference against Bring-Your-Own-API endpoints.
- Privacy & security technical specification section with storage key breakdown.
- Minimalist accordion FAQ covering model weights, browser compatibility, and Ollama/vLLM integration.
- Responsive Chrome extension installation instructions including step-by-step developer unpacked guide.
- Complete open-source documentation suite (`README.md`, `LICENSE`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md`, `CHANGELOG.md`).
