# Getting Support for Mozhi

Thank you for using and exploring Mozhi!

Mozhi is an open-source project maintained independently. While we strive to make the product and website as smooth and accessible as possible, please note that we do not offer dedicated commercial support or real-time help desks.

---

## Where to Get Help

### 1. Website Bug Reports & Technical Issues
If you encounter a broken link, visual glitch, layout issue, or build problem specifically on this website:
- Search existing [GitHub Issues](https://github.com/JeevaVenkidu/mozhi-website/issues) to see if someone has already reported it.
- If not, [Open a New Website Issue](https://github.com/JeevaVenkidu/mozhi-website/issues/new) detailing the browser version, operating system, and steps to reproduce.

### 2. Browser Extension Issues
If you have questions, bug reports, or feature suggestions regarding the **Mozhi Browser Extension** itself (e.g., SmolLM2 model inference, WebGPU execution, popup UI, or ChatGPT insertion):
- Please open an issue in the main [Mozhi Extension Repository](https://github.com/JeevaVenkidu/Mozhi/issues).

### 3. Ideas, Suggestions & General Feedback
- For architectural proposals or enhancement discussions, use [GitHub Discussions](https://github.com/JeevaVenkidu/mozhi-website/discussions) or open a discussion issue on GitHub.

### 4. Security Vulnerabilities
- For security-sensitive issues, please refer to our [Security Policy](SECURITY.md) and do not open a public issue.
